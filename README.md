# Rose Haven Shopify Theme

Starter repository for the Rose Haven storefront rebuild.

## Direction
- Premium, editorial ecommerce aesthetic
- Minimal visible AI influence
- Mobile-first design
- Shopify-native theme architecture
- Warm neutral palette with restrained rose accents

## Structure
- `assets/` — CSS, JavaScript, icons, theme assets
- `config/` — Shopify theme settings
- `layout/` — global theme wrappers
- `locales/` — translations
- `sections/` — modular Shopify sections
- `snippets/` — reusable Liquid partials
- `templates/` — page, product, collection, cart templates

## Suggested first build order
1. Header + announcement bar
2. Homepage hero
3. Featured collection/product cards
4. Editorial brand block
5. Product feature banner
6. Testimonials
7. Footer + newsletter
8. Product page template
9. Collection page template
